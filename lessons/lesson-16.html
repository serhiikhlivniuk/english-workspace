Part 1 · grammar

Three kinds of “if”

0 Zero conditional

If + Present Simple, Present Simple

When: facts, science, things that are always true.
Ukrainian: «якщо …, то завжди …»

If you heat ice, it melts.
If plants don't get water, they die.

1 First conditional

If + Present Simple, will + verb

When: a real possibility in the future and its result.
Ukrainian: «якщо …, то …» (майбутнє)

If it snows tomorrow, we'll build a snowman.
If you don't hurry, you'll miss the bus.

2 Second conditional

If + Past Simple, would + verb

When: imaginary or impossible situations now — dreams, fantasy, advice.
Ukrainian: «якби …, то б …»

If I had a million dollars, I'd buy an island.
If I were you, I'd say sorry.

Never will or would after if: ✗ If it will rain · ✗ If I would have → ✓ If it rains · If I had

Past form ≠ past time. If I had a dog… is about now — I don't have one. The past form just shows it's not real.

were for everybody: If I were you… If he were taller… (was is OK in conversation, but were is better). could = would be able to: If I could fly… · Comma only when if comes first.

Граматика уроку

Три типи умовних речень. Головне питання — наскільки це реально? Завжди правда → zero. Реально може статися → first. Уява, мрія, неможливе зараз → second.

02 · second conditional

Якби… то б…

If I had a million, I'd (would) buy an island.
If I were you, I'd say sorry. (were — для всіх осіб)
If I could fly, I wouldn't take the bus.

Минула форма (had, were, could, lived) тут не про минуле — вона показує, що ситуація нереальна. Українською це «якби … , то б …».
